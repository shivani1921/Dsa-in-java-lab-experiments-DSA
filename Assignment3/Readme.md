Assignment 3: Bubble Sort

Aim: Sort an array by comparing neighbouring values and swapping them when they are out of order.

Tasks

1.  Run one pass of bubble sort on {5, 1, 4, 2, 8}. In the pass, compare each value with the next and swap when the left one is larger. Print each value of the array on its own line.


2.  Sort the array {5, 1, 4, 2, 8} with bubble sort, using one outer loop for the passes and one inner loop for the comparisons. Print each value of the sorted array on its own line.

3.  Sort the array {9, 7, 3} with bubble sort and print each value of the sorted array on its own line.

Assignment 9: Constructors


Aim: Set field values when an object is created, using constructors.
Tasks


1.  Create class Box with int field width and a constructor with no parameters that sets width to 10. In main, create a Box and print Width: followed by the value.


2.  Create class Box with int field width and a constructor that takes an int and sets width using this.width. In main, create a Box with 25 and print Width: followed by the value.


3.  Create class Counter with int field count, set to 0 by its constructor, and method increment() that adds 1 to count. In main, create one Counter, call increment() three times, and print Count: followed by the value.

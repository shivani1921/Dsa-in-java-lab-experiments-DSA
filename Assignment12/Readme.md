Assignment 12: Recursive Factorial, Sum and Power
Aim: Write a method that calls itself on a smaller input until a base case is reached.
Tasks


1.  Write the method int factorial(int n) using recursion. The factorial of 0 is 1, and n times factorial(n - 1) is the other case. Print factorial(5).


2.  Write the method int sum(int n) using recursion that adds the numbers from 1 to n. Print sum(10).


3.  Write the method int power(int base, int exp) using recursion. When exp is 0 the answer is 1; otherwise the answer is base times power(base, exp - 1). Print power(2, 5).

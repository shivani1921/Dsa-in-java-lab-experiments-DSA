Assignment 5: Linear Search


Aim: Search an array one value at a time and report the index where a value is found.
Tasks

1.  Write the method int linearSearch(int[] a, int key) that returns the index of key, or -1 when key is not in the array. Call it with {45, 67, 80, 52, 90} and key 80, and print the result.


2.  Write the method int linearSearch(int[] a, int key) that returns the index of key, or -1 when key is not in the array. Call it with {45, 67, 80, 52, 90} and key 100, and print the result.

 3. Count how many times the value 52 appears in the array {52, 10, 52, 7, 52}. Print the count as Count: followed by the number.

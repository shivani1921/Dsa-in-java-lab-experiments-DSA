Assignment 13: Recursion on Arrays


Aim: Walk through an array with an index that goes one step further in each call.

Tasks



1.  Write the method int sum(int[] a, int i) that returns the sum of the values from index i to the end. Call it on {3, 6, 9, 12, 15} with i = 0 and print the result.


2.  Write the method int max(int[] a, int i) that returns the largest value from index i to the end. Call it on {3, 6, 9, 12, 15} with i = 0 and print the result.


3.  Write the method void printReverse(int[] a, int i) that prints the values from index i down to 0, one per line, using recursion. Call it on {3, 6, 9, 12, 15} with i set to the last index.

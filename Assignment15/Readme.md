Assignment 15: Subsets and Arrangements


Aim: Build answers one choice at a time, print them, and undo each choice before the next one.
Tasks


1.  Print all subsets of {1, 2, 3} using recursion. At each index, first skip the value, then include it. At the end, print the subset in braces, for example {1, 3}, and print {} for the empty subset.


2.  Print all arrangements of the letters a, b and c. Use a used[] array: pick a letter that is not used, mark it used, fill the next position, then unmark it. Print each arrangement on its own line.


3.  Print all arrangements of the letters x and y, one per line, using a used[] array: pick a letter that is not used, mark it used, fill the next position, then unmark it.

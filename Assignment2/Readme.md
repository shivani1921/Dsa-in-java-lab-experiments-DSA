Assignment 2: Largest, Smallest and Count


Aim: Find the largest and smallest value in an array and count values that pass a test.
Tasks

1.  Create the array int[] marks = {45, 67, 80, 52, 90}. Find the largest value with a loop and print it as Largest: followed by the value.


2.  Create the array int[] marks = {45, 67, 80, 52, 90}. Find the smallest value with a loop and print it as Smallest: followed by the value.


3.  Create the array int[] marks = {45, 67, 80, 52, 90}. Count the values greater than 60 and print the count as Count: followed by the number

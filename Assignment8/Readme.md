Assignment 8: Classes and Objects

Aim: Write a small class with fields and a method, and create objects from it.

Tasks

1.  Create class Student with int roll, String name and method show() that prints Roll: and the roll, then Name: and the name. In main, create a Student with roll 5 and name Rohan and call show().


2.  Create class Student with int roll, String name and method show() that prints Roll: and the roll, then Name: and the name. Create two Students: roll 5 named Rohan, and roll 8 named Meera. Call show() on each.


3.  Create class Book with int pages and method isLong() that returns true when pages is more than 300. In main, create a Book with 450 pages and one with 120 pages, and print isLong() for each, one per line.

Assignment 1: Reading Array Values
Aim: Read values from an array by index and by a loop.
Tasks
1.  Create the array int[] marks = {45, 67, 80, 52, 90}. Print First: followed by the first value and Last: followed by the last value, on two lines, using indexes.
2.  Create the array int[] marks = {45, 67, 80, 52, 90}. Print every value on its own line, using a for loop.
3.  Create the array int[] marks = {45, 67, 80, 52, 90}. Add all the values with a loop and print the total as Sum: followed by the total.

Assignment 4: Selection Sort


Aim: Sort an array by finding the smallest value in the unsorted part and moving it to the front.


Tasks

1.  Find the index of the smallest value in the array {64, 25, 12, 22, 11} with a loop, and print that index.

2.  Sort the array {64, 25, 12, 22, 11} with selection sort. For each position, swap in the smallest value of the rest. Print each value of the sorted array on its own line.

3.  Do only the first step of selection sort on {64, 25, 12, 22, 11}: find the smallest value, swap it with the first value, and print each value of the array on its own line.
